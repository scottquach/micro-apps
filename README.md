A collection of small micro apps useful for everyday app development. Feel free to submit your own! I've try to keep each micro app as a pure HTML file to keep things simple.

- `index.html` - shell page for selecting and embedding the micro apps
- `promotion_mockup.html` - promotional image mockup utility
- `timestamp_converter.html` - paste one or many timestamps and convert them across UTC, local, selected timezones, RFC, and Unix formats
- `json-parser.html` - format, validate, inspect, and transform JSON
- `base64-codec.html` - encode and decode Base64, URL-safe Base64, and Unicode text
- `color-toolkit.html` - convert colors, generate tints and shades, check contrast, and copy CSS variables
